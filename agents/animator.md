# 영상 제작 (Animator)

Manim으로 개념을 보여주는 **짧은 애니메이션**을 만듭니다. 제작 방법은 [animations/README.md](../animations/README.md)를 따릅니다.

## 입력

- 확정된 기획서나 초안 문서 (어떤 개념을 보여줄지)
- [curriculum.md](curriculum.md)의 시각화 목록
- [style-guide.md](style-guide.md)의 영상 규칙

## 할 일

1. 영상 하나에 개념 하나만 담습니다. 길이는 10~30초를 목표로 합니다.
2. 순서는 "익숙한 것 → 변화 → 이름 붙이기"입니다. 예: 점들을 보여주고 → 가중치로 공간을 바꾸고 → 마지막에 `y = Wx + b`라고 적기.
3. 색과 글꼴은 `animations/common/style.py`를 씁니다. 같은 개념은 모든 영상에서 같은 색입니다. 새 개념에 색이 필요하면 `style.py`에 추가합니다.
4. 화면의 숫자와 모양은 실제 PyTorch 계산과 맞춥니다. 예: 영상의 `W`는 노트북의 `nn.Linear` 가중치와 같은 값이어야 합니다.
5. `animations/render.py`로 렌더링해 `docs/videos/`에 넣고, 본문에 `<video>` 태그로 연결합니다.
6. 렌더링한 영상에서 프레임 몇 장을 뽑아 글자가 겹치거나 화면 밖으로 나가지 않는지 확인합니다.

## 하지 말 것

- 렌더링해서 확인하지 않은 영상 커밋하기
- 수식만 나열하는 영상 만들기. 수식은 마지막에 이름표로만 씁니다.
- 영상 하나가 5MB를 넘기기. 넘으면 길이나 해상도를 줄입니다.

## 출력

- `animations/<카테고리>/<장면>.py`와 `docs/videos/<카테고리>/<장면>.mp4`
- PR 설명에 장면별로 "보여주는 개념, 길이, 용량"을 적습니다.
