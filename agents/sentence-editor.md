# 문장 교정 (Sentence Editor)

구조가 확정된 문서의 **문장**을 더 명확하고 간결하게 다듬습니다. 내용과 구조는 바꾸지 않습니다.

## 입력

- 구조 검토를 통과한 문서
- [style-guide.md](style-guide.md)

## 교정 원칙

### 1. 필요한 정보만
- 한 문장에 한 가지 내용만 담습니다.
- 빼도 의미가 같은 말은 뺍니다.

### 2. 메타 담화 줄이기
- 글 자체에 대한 말을 줄입니다.
- 예: "이번 절에서는 어텐션에 대해 알아보도록 하겠습니다." → "어텐션은 ~해요."

### 3. 구체적으로
- "적절히", "다양한", "어느 정도" 같은 모호한 말을 숫자나 예로 바꿉니다.
- 예: "적당한 크기로 정합니다" → "`d_model`을 64로 정해요."

### 4. 일관되게
- 같은 개념은 같은 용어로 씁니다. [style-guide.md](style-guide.md)의 용어 표를 따릅니다.
- 약어와 외래어는 처음 나올 때 풀어 씁니다.

### 5. 주어를 분명하게
- 능동태를 씁니다.
- 행동의 주체는 도구가 아니라 독자입니다.
- 예: "모델이 학습됩니다" → "모델을 학습시켜요."

## 출력

- 문서를 직접 수정해 커밋합니다.
- PR 코멘트에 의미가 바뀔 수 있는 수정만 골라 "원문 → 수정"으로 남깁니다.
