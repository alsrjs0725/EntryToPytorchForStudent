# 커리큘럼

> 이 문서는 **관리자가 직접 관리**합니다. 에이전트는 이 문서를 읽기만 하고, 바꿀 필요가 있으면 PR 설명에 제안으로 남깁니다.

## 최종 목표

토크나이저와 레이어 개념에서 출발해, 트랜스포머로 띄어쓰기 모델을 만들고, 마지막에 작은 LLM을 직접 구현합니다.

## 카테고리

각 카테고리의 문서는 앞 카테고리 내용만 알면 읽을 수 있어야 합니다.

| 번호 | 카테고리 | 다루는 내용 | 끝나면 할 수 있는 것 |
| --- | --- | --- | --- |
| 00 | 준비 | 개발 환경, 텐서, 자동 미분, 학습 루프 | 간단한 모델을 학습시키고 손실이 줄어드는 것을 확인 |
| 01 | 토크나이저 | 문자/단어/서브워드 토큰화, 어휘집, 인코딩과 디코딩 | 문장을 정수 시퀀스로 바꾸고 되돌리기 |
| 02 | 레이어 | 선형 레이어, 활성화 함수, 임베딩, 정규화, `nn.Module` | 레이어를 조합해 모델 클래스 만들기 |
| 03 | 트랜스포머 | 어텐션, 멀티헤드 어텐션, 위치 정보, 트랜스포머 블록 | 트랜스포머 블록을 직접 구현하기 |
| 04 | 띄어쓰기 모델 | 데이터 준비, 시퀀스 라벨링, 학습과 평가 | 붙여 쓴 문장의 띄어쓰기 복원하기 |
| 05 | 기초 LLM | 다음 토큰 예측, 디코더 전용 모델, 생성(샘플링) | 작은 말뭉치로 학습한 모델로 문장 생성하기 |
