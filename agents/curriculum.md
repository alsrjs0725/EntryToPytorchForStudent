# 커리큘럼

> 이 문서는 **관리자가 직접 관리**합니다. 에이전트는 이 문서를 읽기만 하고, 바꿀 필요가 있으면 PR 설명에 제안으로 남깁니다.

## 최종 목표

레이어를 눈으로 확인하며 이해하고, 이를 바탕으로 트랜스포머로 띄어쓰기 모델을 만든 뒤, 작은 LLM을 직접 구현합니다.

## 전제

- 모든 실습은 **Google Colab 무료 GPU**에서 합니다. 로컬 설치는 다루지 않습니다.
- 환경 설정은 "Colab 열기 → 런타임 유형을 GPU로 변경 → 첫 셀 실행" 3단계로 끝냅니다.

## 설계 원칙

레이어 챕터에서 **레이어 하나가 무엇을 하는지 시각화**로 충분히 보여줍니다.
이후 챕터는 레이어를 "입력 모양을 받아 출력 모양을 내는 상자"로 추상화해 설명합니다.
그래서 뒤 챕터에서 새 구조(어텐션, 트랜스포머 블록)가 나오면 "어떤 레이어를 어떻게 쌓았는가"로 설명할 수 있어야 합니다.

## 카테고리

각 카테고리의 문서는 앞 카테고리 내용만 알면 읽을 수 있어야 합니다.

| 번호 | 카테고리 | 다루는 내용 | 끝나면 할 수 있는 것 |
| --- | --- | --- | --- |
| 00 | 시작하기 | Colab 사용법, GPU 확인, 텐서 기초 | Colab에서 텐서를 만들고 GPU로 옮기기 |
| 01 | 레이어 - 이론 | 레이어란 무엇인가, 가중치와 편향, 순전파, 손실, 역전파와 경사 하강법, 학습 루프 | 레이어 하나가 입력을 어떻게 바꾸고, 학습으로 어떻게 변하는지 그림으로 설명하기 |
| 02 | 레이어 - 실제 구조와 종류 | `nn.Module`, 선형, 활성화 함수, 임베딩, 정규화, 드롭아웃, 레이어 쌓기 | 레이어를 조합해 모델 클래스를 만들고 각 레이어의 입출력 모양 설명하기 |
| 03 | 토크나이저 | 문자/단어/서브워드 토큰화, 어휘집, 인코딩과 디코딩 | 문장을 정수 시퀀스로 바꾸고 임베딩 레이어에 넣기 |
| 04 | 트랜스포머 | 어텐션, 멀티헤드 어텐션, 위치 정보, 트랜스포머 블록 | 트랜스포머 블록을 레이어 조합으로 직접 구현하기 |
| 05 | 띄어쓰기 모델 | 데이터 준비, 시퀀스 라벨링, 학습과 평가 | 붙여 쓴 문장의 띄어쓰기 복원하기 |
| 06 | 기초 LLM | 다음 토큰 예측, 디코더 전용 모델, 생성(샘플링) | 작은 말뭉치로 학습한 모델로 문장 생성하기 |

### 01 레이어 - 이론에서 보여줄 시각화

- 2차원 점들을 선형 레이어에 통과시켜 공간이 늘어나고 회전하는 모습
- 활성화 함수 전후로 공간이 접히는 모습
- 학습 중 결정 경계와 손실 곡선이 변하는 모습
- 가중치 행렬을 히트맵으로 보기
