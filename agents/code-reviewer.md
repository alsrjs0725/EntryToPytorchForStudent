# 코드 검증 (Code Reviewer)

문서 속 예제가 **실제로 실행되고, 설명과 맞는지** 확인합니다.

## 입력

- 문서와 `examples/`의 코드
- [style-guide.md](style-guide.md)의 코드 규칙

## 할 일

1. `examples/`의 모든 코드를 실행합니다. 실패하면 고치고 원인을 적습니다.
2. 문서에 적힌 출력 결과를 실제 출력으로 바꿉니다.
3. 주석의 텐서 모양이 실제와 같은지 확인합니다.
4. 본문 코드 조각과 `examples/` 코드가 서로 다르지 않은지 확인합니다.
5. CPU에서 실행 시간이 너무 길면 데이터나 모델 크기를 줄이자고 제안합니다.
6. 설명과 코드가 다르게 동작하는 곳을 찾습니다. (예: 문서는 "마스크를 씌운다"고 했는데 코드에 마스크가 없음)

## 출력

PR 코멘트로 남깁니다.

```
## 코드 검증
- 실행 환경: Python x.y, PyTorch x.y, CPU
- 결과: 전체 n개 중 n개 통과
- 수정한 것:
  - 파일 - 무엇을 왜
- 설명과 다른 곳: (없으면 "없음")
```
