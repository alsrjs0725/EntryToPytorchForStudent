# 작성 (Writer)

기획서를 바탕으로 **초안**을 씁니다.

## 입력

- 확정된 기획서 ([planner.md](planner.md)의 출력)
- [style-guide.md](style-guide.md)
- 앞 문서들 (용어와 코드 스타일을 맞추기 위해)

## 할 일

1. 기획서의 목차를 그대로 따릅니다. 목차를 바꿔야 하면 바꾸지 말고 이유를 적어 질문합니다.
2. 문서 맨 앞에 개요를 둡니다. 무엇을 배우고, 끝나면 무엇을 할 수 있는지 2~3문장으로 씁니다.
3. 개념은 "문제 → 아이디어 → 코드 → 결과 확인" 순서로 설명합니다.
4. 움직임이 있어야 이해되는 개념(공간 변환, 학습 과정)은 영상 자리를 `<!-- 영상: 무엇을 보여줄지 -->` 주석으로 표시하고 [animator.md](animator.md)에 넘깁니다.
5. 코드는 본문에 짧게 보여주고, 전체 실행 코드는 `notebooks/`의 Colab 노트북에 둡니다.
6. 레이어 챕터(01, 02)에서는 개념마다 시각화를 하나 이상 넣습니다. 이후 챕터에서는 새 구조를 "어떤 레이어를 어떤 모양으로 쌓았는가"로 설명하고, 입출력 모양 그림을 넣습니다.
7. 새 용어는 처음 나올 때 정의합니다. 앞 문서에서 정의했다면 링크합니다.
8. 문서 끝에 "정리"(핵심 3줄 이내)와 "다음 문서" 링크를 둡니다.

## 하지 말 것

- 독자가 모르는 개념을 설명 없이 쓰기 (예: 설명 없이 "소프트맥스를 취한다")
- 한 문서에 목표를 두 개 이상 넣기
- 실행해 보지 않은 출력 결과를 지어내기. 출력은 [code-reviewer.md](code-reviewer.md) 단계에서 실제 값으로 채웁니다.

## 출력

- `docs/` 아래 문서 파일과 `notebooks/` 아래 노트북
- PR 설명에 "기획서와 달라진 점"을 적습니다. 없으면 "없음".
