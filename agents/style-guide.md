# 스타일 가이드

모든 역할이 공통으로 따릅니다.

## 독자

- 컴퓨터 분야 대학교 2학년. 파이썬 문법, 함수, 클래스, 리스트/딕셔너리는 익숙합니다.
- 선형대수 기본 연산(행렬 곱, 전치 등)은 압니다. 연산 자체는 설명하지 않고, PyTorch에서 어떻게 쓰는지만 보여줍니다.
- 머신러닝과 미분은 거의 모른다고 가정합니다. 필요하면 그 문서 안에서 짧게 설명합니다.
- 독자는 "왜 이렇게 하는지"를 알고 싶어 합니다. 수식보다 코드와 그림으로 먼저 보여줍니다.

## 문체

- 한국어, 해요체를 씁니다. ("~해요", "~합니다" 섞지 않기)
- 한 문장에는 한 가지 내용만 담습니다.
- 주어는 독자입니다. "이 함수가 해줍니다"보다 "이 함수로 ~할 수 있어요"를 씁니다.
- 이모지는 쓰지 않습니다.

## 용어

- 같은 개념은 문서 전체에서 같은 단어로 씁니다.
- 영어 용어는 처음 나올 때 한글과 영어를 함께 적습니다. 예: 임베딩(embedding)
- 자주 쓰는 표기는 아래 표를 따릅니다. 새 용어가 생기면 이 표에 추가를 제안합니다.

| 쓰는 표기 | 쓰지 않는 표기 |
| --- | --- |
| 텐서 | 텐서값, tensor |
| 레이어 | 층, 계층 |
| 토큰 | 단어 조각 |
| 학습 | 훈련, 트레이닝 |
| 손실 | 로스, 오차 함수 |

## 코드

- Google Colab 무료 GPU(T4) 기준입니다. Colab에 기본 설치된 PyTorch를 쓰고, 추가 설치는 최소로 합니다.
- 노트북 첫 셀은 GPU 확인과 `device` 설정입니다. 예: `device = "cuda" if torch.cuda.is_available() else "cpu"`
- 예제는 셀 순서대로 실행하면 끝까지 돌아야 합니다. import부터 포함합니다.
- 무료 Colab 세션 안에서 끝나도록 학습은 셀 하나당 10분 이내로 만듭니다.
- 텐서를 다루는 줄에는 모양(shape)을 주석으로 적습니다. 예: `# (batch, seq_len, d_model)`
- 결과가 정해지도록 `torch.manual_seed(0)`를 씁니다.
- 개념은 그래프나 그림으로 먼저 보여줍니다. 시각화는 matplotlib을 씁니다.
- 처음에는 직접 구현하고, 그다음에 PyTorch 내장 기능과 비교합니다.

## 영상

- Manim Community로 만들고, 색과 글꼴은 `animations/common/style.py`를 따릅니다.
- 같은 개념은 모든 영상과 그림에서 같은 색입니다. 입력은 파랑, 가중치는 주황, 편향은 청록, 출력은 노랑, 손실은 빨강입니다.
- 영상 속 한글 문장도 이 문서의 문체 규칙을 따릅니다.
